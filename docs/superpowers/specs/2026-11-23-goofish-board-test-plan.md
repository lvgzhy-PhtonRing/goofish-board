## L4 — 异常与边界

| # | 用例 | 构造方式 | 通过标准 |
|---|------|----------|----------|
| 4.1 | 缓存过期 | 云端把 `fetched_at` 改成 37 小时前 | 看板显示「超过 36 小时」；阻断下架/复测；静置满 24h 打卡仍可用 |
| 4.2 | 缓存不完整 | `complete=false` | 显示「数据不完整」并阻断新开始操作 |
| 4.3 | 配额锁定 | 连点 3 次「记录上新」 | 第 4 次按钮禁用，直接调接口返回 400/锁定提示 |
| 4.4 | 双开并发 | 两个标签同时点「记录上新」 | 乐观锁重试后成功或明确冲突提示，不覆盖丢数据 |
| 4.5 | 图片防盗链 | 断网 CDN 或查看 alicdn 图 | 显示占位，不破版 |
| 4.6 | 窄屏 375px | 手机/DevTools | 单列卡片、无横向溢出 |
| 4.7 | 会话过期 | 篡改 localStorage expiresAt | 自动刷新或回登录页，不白屏 |
| 4.8 | 云端不可达 | 断网打开 | 明确错误提示，不无限 loading |

## 已知限制

- 周日复核（3.2.10）与 24h 倒计时（3.2.8）无法在生产即时验证，需时间推移或临时改库时间（测试后恢复）。
- 移动端仅做布局可用性检查，不做触控手势专项。
